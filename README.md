# Myntra Fashion & Clothing Analysis

An Excel-based data analysis case study on 526K+ Myntra fashion products, focusing on data cleaning, pricing, ratings, discounts, product availability and lookup based analysis.

## Project Overview

This project analyzes a Myntra fashion product catalogue containing 526,564 product records.

The analysis involved cleaning and standardizing the dataset, handling missing values and extracting insights related to product pricing, ratings, discounts and size availability using Microsoft Excel.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Conditional Analysis
- Lookup Functions

## Data Preparation

The dataset was prepared for analysis through several cleaning steps:

- Checked the dataset for duplicate records
- Standardized discount offers into a consistent percentage format
- Repaired missing discount prices using category-level averages
- Replaced missing size values with `Not Available`
- Prepared fields for consistent analysis

## Analysis Performed

The analysis focused on:

- Product pricing across different rating levels
- High discount product distribution
- Product availability by size
- Product level information retrieval using lookup functions
- Classification of products based on discount levels

## Key Insights

- **526,564** product records were analyzed.
- **221,864** products had discounts above 50%.
- **308,460** products were available in size M.
- Products rated above 4 stars had an average original price of **₹1,966.67**.
